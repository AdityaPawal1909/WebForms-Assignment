# 🌐 Web Forms Application

A practical **ASP.NET Web Forms** application developed to build a strong foundation in server-side web development using C# and the .NET ecosystem.

## 📌 Overview

This project focuses on understanding the fundamentals of **ASP.NET Web Forms**, including web form structure, server-side processing, controls, events, and the request–response model.

It is part of my practical journey toward developing professional .NET-based web applications.

The project was created to:

## 🚀 Getting Started

### Prerequisites

* Visual Studio
* Compatible .NET Framework / .NET environment required by the project
* A supported web browser

### Run Locally

1. Clone the repository:

```bash
git clone https://github.com/piyushlohar2008-byte/Webform.git
```

2. Open the solution in **Visual Studio**.

3. Restore or configure the required project dependencies.

4. Build the solution.

5. Run the application using Visual Studio.
